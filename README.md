# mtk-apusys-firmware

APUSYS is a proprietary hardware in Mediatek SoC to support AI operations.
This repo provides firmwares of APUSYS.



## Kernel space

In kernel space, firmwares works with the APUSYS kernel driver to executing Neural Network modles with hardware acceleration.


## Branch

- The main branch is unused. 

- For i1200 platform: use `mt8195` branch. It is still under development and subject to design changes.
